# Ček lista za glasanje

## 6:00 - Priprema

- [ ] Fotografisati zatvornicu na džaku.
- [ ] Zatvornica se čuva na sigurnom mestu.
- [ ] Otvaranje džaka (učestvuje više članova BO).
- [ ] Pregledanje izbornog materijala i upoređivanje sa zapisnikom.
- [ ] Prebrojavanje listića.
- [ ] Broj listića jednak broju upisanih u birački spisak i spisak naknadnih promena.
- [ ] Provera UV lampe i sprejeva.
- [ ] Pravilno postavljene kabine i paravani.
- [ ] Istaknuta zbirna izborna lista.
- [ ] Istaknuta zastava RS.
- [ ] Istaknuti plakati o zabrani upotrebe mobilnih telefona.
- [ ] Istaknut broj biračkog mesta.
- [ ] Obeležen red za svako biračko mesto.
- [ ] Svi članovi BO imaju istaknute identifikacione kartice.
- [ ] Svi posmatrači imaju istaknute identifikacione kartice.
- [ ] Nema propagandnog materijala na i oko BM.
- [ ] Uklonjene kante za smeće iz hodnika zgrade.
- [ ] Uklonjene kante za smeće sa ulaza BM.
- [ ] Upisane tačke 1-4 u zapisnik o radu BO.
- [ ] Upisana imena prisutnih posmatrača u zapisnik o posmatračima.
- [ ] Javiti broj upisanih u birački spisak i broj prijavljenih za glasanje van BM.

## 7:00 - Otvaranje

- [ ] Upisano vreme otvaranja BM u zapisnik.
- [ ] Prvi birač nije član BO.
- [ ] Upisano ime prvog birača u zapisnik.
- [ ] Kontrolni list ubačen u kutiju.
- [ ] Kutija pravilno zapečaćena (nalepnica sa grbom).
- [ ] Pravilan redosled izbornih radnji.
- [ ] Listići se pravilno čuvaju.

## 8:00

- [ ] Javiti izlaznost.

## 20:00 - Zatvaranje

- [ ] Član BO stao na kraj reda.
- [ ] Zaključana prostorija.
- [ ] Javiti izlaznost.
- [ ] Svi članovi ili njihovi zamenici prisustvuju brojanju.
- [ ] Jedan član BO pazi na materijal, džak i zapisnik.

### Pre otvaranja kutije

- [ ] Zalepiti otvor kutije.
- [ ] Prebrojani neupotrebljeni listići.
- [ ] Broj neupotrebljenih listića upisan u zapisnik.
- [ ] Neupotrebljeni listići su upakovani i zatvoreni u koverte.
- [ ] Pripremljen kontrolni formular.
- [ ] Ukupan broj birača upisan u kontrolni formular.
- [ ] Broj izašlih birača upisan u kontrolni formular.

### Brojanje

- [ ] Kontrolni list je u kutiji.
- [ ] Kontrolni list se čuva na bezbednom mestu.
- [ ] Javiti prve rezultate.
- [ ] Broj važećih listića upisan u kontrolni formular.
- [ ] Broj nevažećih listića upisan u kontrolni formular.
- [ ] Broj glasova po listama upisan u kontrolni formular.
- [ ] Logičko-računska kontrola.

### Zapisnik

- [ ] Popuniti zapisnik.
- [ ] Popuniti zapisnik o posmatračima.
- [ ] Fotografisati zapisnik.
- [ ] Fotografisati sve primedbe članova BO.
- [ ] Fotografisati sve primedbe posmatrača.
- [ ] Poslati zapisnik.
- [ ] 3\. primerak zapisnika istaknut na ulazu BM.

### Pakovanje materijala

- [ ] Spakovan kontrolni list.
- [ ] Spakovani nevažeći listići.
- [ ] Spakovani važeći listići.
- [ ] Spakovane potvrde o izbornom pravu.
